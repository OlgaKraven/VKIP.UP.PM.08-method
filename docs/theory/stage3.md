# Этап 3. Интерфейс администратора и UX CRUD

## 1. Dashboard

Dashboard должен давать быстрый обзор состояния системы:

- количество основных записей;
- новые заявки/заказы/записи;
- последние действия пользователей;
- проблемные состояния;
- быстрые ссылки на создание новой записи.

## 2. Таблицы

Таблица — главный рабочий элемент админ-панели. Она должна быть удобна для просмотра и поиска.

| Возможность | Требование |
|-------------|------------|
| Поиск | по ключевым полям |
| Фильтры | по статусу, категории, дате |
| Сортировка | по дате, названию, статусу |
| Пагинация | не выводить все записи сразу |
| Действия | просмотр, редактирование, удаление |
| Состояния | загрузка, пустой список, ошибка |

## 3. Формы

Форма должна помогать пользователю заполнить данные без ошибок.

Обязательные элементы:

- подписи полей;
- отметка обязательных полей;
- подсказки;
- валидация;
- сообщения об ошибках;
- кнопки «Сохранить», «Отмена»;
- подтверждение удаления.

## 4. Модальные окна и уведомления

Для коротких действий подходят модальные окна: подтверждение удаления, изменение статуса, просмотр деталей. После операций показываются уведомления: «Запись создана», «Изменения сохранены», «Ошибка доступа».

## 5. Адаптивность

Админ-панель должна корректно работать на ширине ноутбука и планшета. На мобильном виде допускается упрощённая таблица или карточки, но текст и кнопки не должны накладываться друг на друга.

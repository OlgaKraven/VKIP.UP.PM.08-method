## Обязательные сущности

Для любого варианта должны быть реализованы:

1. `users` — пользователи админ-панели.
2. `roles` — роли и права доступа.
3. `activity_log` — журнал действий.
4. 4-6 предметных таблиц выбранной области.
5. справочник статусов или категорий.

## Минимальные административные сценарии

1. Администратор входит в систему и видит dashboard.
2. Администратор создаёт, редактирует, удаляет и ищет записи в основных разделах.
3. Оператор работает только с разрешёнными разделами.
4. Все критичные действия попадают в журнал действий.
5. Ошибки валидации показываются рядом с полями формы.
6. Проект запускается по инструкции из репозитория.

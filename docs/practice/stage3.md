# Этап 3. Реализация frontend админ-панели

## Задание

На этапе нужно реализовать полноценный пользовательский интерфейс админ-панели.

## Что сделать

1. Реализовать страницу входа.
2. Реализовать общий layout: sidebar, header, зона контента.
3. Реализовать dashboard.
4. Реализовать CRUD-разделы для минимум 4 сущностей.
5. Добавить таблицы с поиском, фильтрами, сортировкой и пагинацией.
6. Добавить формы создания и редактирования.
7. Добавить подтверждение удаления.
8. Добавить уведомления об успешных действиях и ошибках.
9. Реализовать страницу журнала действий.
10. Проверить адаптивность.

## Минимальные экраны

| Экран | Что должно быть |
|-------|-----------------|
| Login | поля логина/пароля, ошибка входа |
| Dashboard | карточки статистики, последние действия |
| Список сущности | таблица, поиск, фильтры, действия |
| Форма сущности | создание/редактирование, валидация |
| Пользователи | список, роль, статус, блокировка |
| Журнал действий | фильтр по пользователю, действию, дате |

## Требования к интерфейсу

- интерфейс должен быть рабочим, а не макетом;
- кнопки должны выполнять действия;
- длинные таблицы должны иметь пагинацию;
- ошибки должны быть понятны пользователю;
- нельзя показывать пользователю технические stack trace;
- удаление должно требовать подтверждения;
- активный раздел меню должен быть виден;
- проект должен выглядеть цельно и аккуратно.

## Что приложить к итоговым материалам

1. Скриншот dashboard.
2. Скриншоты минимум 4 CRUD-разделов.
3. Скриншот формы с ошибками валидации.
4. Скриншот журнала действий.
5. Скриншот страницы пользователей и ролей.
6. Инструкцию запуска frontend.

# Этап 4. Защита, тестирование и сдача проекта

## Задание

На этапе нужно довести админ-панель до демонстрационного состояния: проверить безопасность, роли, журнал действий, подготовить запуск и итоговые материалы.

## Что сделать

1. Проверить вход и выход.
2. Проверить доступы для всех ролей.
3. Проверить CRUD по всем основным сущностям.
4. Проверить журнал действий.
5. Проверить, что пароли не хранятся открытым текстом.
6. Проверить, что `.env` не попал в репозиторий.
7. Подготовить README с инструкцией запуска.
8. Подготовить тестовый логин и пароль для демонстрации.
9. Подготовить итоговые материалы в форме, установленной преподавателем.

## Сценарии проверки

| № | Сценарий | Ожидаемый результат |
|:--:|----------|---------------------|
| 1 | Вход admin | открыт dashboard |
| 2 | Вход с неправильным паролем | показана ошибка |
| 3 | Открыть `/admin` без входа | перенаправление на login |
| 4 | Создать запись | запись появилась в таблице |
| 5 | Изменить запись | данные обновились |
| 6 | Удалить запись | требуется подтверждение |
| 7 | Действие без прав | доступ запрещён |
| 8 | Проверить журнал | действие записано |

## Требования к репозиторию

В репозитории должны быть:

- исходный код;
- миграции или SQL-скрипты;
- seed-данные;
- `.env.example`;
- `README.md` с инструкцией запуска;
- скриншоты или папка `docs/`;
- список тестовых пользователей без реальных секретов.

# Этап 1. Проектирование админ-панели

## Задание

На этапе нужно выбрать предметную область и спроектировать будущую админ-панель до начала кодирования.

## Что сделать

1. Выбрать вариант из [списка предметных областей](../subject_areas.md).
2. Описать пользователей системы и их роли.
3. Составить карту разделов админ-панели.
4. Определить 4-6 основных сущностей предметной области.
5. Спроектировать ER-схему базы данных.
6. Нарисовать прототип основных экранов.
7. Подготовить список API-маршрутов или MVC-страниц.

## Минимальная карта админ-панели

```text
/login
/admin/dashboard
/admin/users
/admin/roles
/admin/<entity-1>
/admin/<entity-2>
/admin/<entity-3>
/admin/<entity-4>
/admin/activity-log
/admin/settings
```

## Таблица ролей

| Роль | Разделы | Разрешённые действия |
|------|---------|----------------------|
| admin | все разделы | создание, просмотр, редактирование, удаление |
| manager/operator | рабочие разделы | создание, просмотр, редактирование |
| viewer | ограниченные разделы | только просмотр |

## Что приложить к итоговым материалам

1. Описание предметной области.
2. Карта разделов админ-панели.
3. ER-схема.
4. Прототип dashboard и одной CRUD-страницы.
5. Таблица ролей и прав.
6. Список сущностей и полей.

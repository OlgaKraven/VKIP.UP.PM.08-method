# Учебная практика ПМ.08 «Разработка веб-приложений»

Комплект методических материалов для учебной практики по ПМ.08 с итоговой работой: **создание полноценной административной панели веб-приложения**.

Опубликованные материалы:

- методический комплект: https://github.com/OlgaKraven/VKIP.UP.PM.08-method
- полноценный пример проекта: https://github.com/OlgaKraven/VKIP.UP.PM.08-projectWork

## Состав

- `docs/index.md` — главная страница: цель, задачи, структура практики, требования к админ-панели.
- `docs/subject_areas.md` — варианты предметных областей для админ-панели.
- `docs/theory/stage1-4.md` — теоретические материалы по архитектуре, backend, frontend, безопасности и публикации.
- `docs/practice/stage1-4.md` — практические этапы выполнения проекта.
- `student_web_admin_samples/` — полноценный учебный пример Flask-админки: структура проекта, модели, маршруты, шаблоны, схема БД, seed-данные, `.env.example`.

## Запуск сайта документации

```bash
pip install mkdocs mkdocs-material pymdown-extensions
mkdocs serve -a 127.0.0.1:8008
```

## Сборка

```bash
mkdocs build
```
